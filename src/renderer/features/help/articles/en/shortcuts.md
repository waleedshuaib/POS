# Keyboard Shortcuts

## POS screen
- **Enter** in search field: adds the first result or the barcode-matching product.
- **Esc** in the payment modal: close it.

## General
- **Ctrl+F** (on some pages): move focus to the search input.
- **Esc**: close any open modal.

More shortcuts will be added in future releases. Request any you need via *Help* → Diagnostics → Report issue.

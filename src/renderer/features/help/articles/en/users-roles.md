# Users & Roles

## Three roles
- **Admin**: Full access, including user management and sensitive settings.
- **Manager**: Sales, products, inventory, purchases, reports.
- **Cashier**: Sales, customers, drawer, limited reports.

## Add a user
From *Users* (admin only), click **Add user** and enter:
- Unique username.
- Full name.
- Initial password (can be changed later).
- Role.

## Disable a user
Instead of deleting, uncheck **Active** in the edit form. The record stays for audit purposes.

## Change a password
From the edit form, type a new password in the **Reset password** field.

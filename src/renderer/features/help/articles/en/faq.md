# FAQ

## Does it work without internet?
Yes, fully. All data lives locally in a SQLite database. Internet is only needed during initial install.

## Is my data safe?
- Passwords are hashed with Argon2.
- The database is local on your machine; nothing is sent to any server.
- You can export a backup any time.

## Can I use it on multiple machines?
Each install runs independently. Syncing across devices requires an add-on coming in a future release.

## What about tax and tax invoices?
Every product has a configurable tax rate. The default rate is set in *Settings*. Tax shows on the receipt.

## How do I import an existing product list?
This release is manual entry. CSV import is coming soon.

## Is the app free?
This is a review-grade release. Contact the maintainer for licensing terms.

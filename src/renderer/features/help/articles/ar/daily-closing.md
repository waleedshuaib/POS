# إقفال اليوم

قبل بدء يوم البيع: **افتح الصندوق** من *الصندوق* وأدخل المبلغ الابتدائي.

خلال اليوم، كل مبيعة نقدية ترفع *المتوقع*، وكل باقٍ يُخصم تلقائياً.

عند انتهاء الوردية:
1. اعدّ النقد فعلياً.
2. أدخل المبلغ المعدود.
3. يحسب النظام الفرق (**variance**) ويحفظ سجل الإقفال.

- فرق صفر = المطابقة تامة.
- فرق سالب = نقص في الصندوق.
- فرق موجب = فائض (راجع الإيصالات).

يعرض *الصندوق* سجل الإقفالات السابقة كمرجع محاسبي.

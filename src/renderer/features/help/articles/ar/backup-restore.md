# النسخ الاحتياطي والاستعادة

## النسخ الاحتياطي
من *الإعدادات* → **نسخ احتياطي** اضغط **تصدير نسخة**. يطلب التطبيق مكان حفظ ملف مضغوط يحوي:
- قاعدة البيانات الكاملة.
- مجلد صور المنتجات.

احفظ هذا الملف دورياً على وسيط خارجي (USB، تخزين سحابي شخصي...).

## الاستعادة
اضغط **استعادة نسخة** واختر ملف zip سابق. سيحل محل البيانات الحالية، ويُنصح بإعادة تشغيل التطبيق بعد ذلك.

⚠️ **تحذير**: الاستعادة تطمس البيانات الحالية. اعمل نسخة احتياطية قبل الاستعادة!

## الموقع الفعلي
- **macOS**: `~/Library/Application Support/pos/pos.db`
- **Windows**: `%APPDATA%\pos\pos.db`

يمكنك نسخ هذه الملفات يدوياً أيضاً.
